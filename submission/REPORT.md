\## 2. How CrewAI works



CrewAI is a framework used to build multi-agent systems in which different AI agents work together to complete a task.



My project uses three agents: Research Analyst, Technical Writer, and Editor. Each agent has a specific role, goal, and backstory. The researcher collects important facts and identifies open questions. The writer uses the research results to create an explainer. Finally, the editor reviews the content and identifies claims that require supporting sources.



CrewAI organizes these agents and their responsibilities using tasks. The agents and tasks are combined into a crew. My project uses a sequential process, meaning each task is completed in order and the next task receives the previous task's output.



By modifying the editor task description, I changed the instructions given to the final agent. This demonstrates how CrewAI allows developers to control agent behavior through roles, goals, tasks, and process configuration.

\## 4. Choosing a framework



I would choose CrewAI for projects that require multiple specialized agents to collaborate on a sequence of tasks. It provides a straightforward way to define agents, assign responsibilities, and organize their workflow. It is useful for research, writing, reviewing, and other tasks that can be divided among different roles.



Another framework from the workshop is LangGraph. LangGraph provides more explicit control over workflow structure through nodes, edges, and state management. This can be useful when a project requires conditional decisions, repeated steps, or more complex workflows.



Compared with LangGraph, CrewAI makes it easier to organize a team of specialized agents using roles and tasks. However, LangGraph may provide more flexibility when developers need detailed control over how information moves through a workflow.



For my project, CrewAI was a suitable choice because the research, writing, and editing activities could be organized into a simple sequential process.
